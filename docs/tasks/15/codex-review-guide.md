## Self-review вместо Codex

Прогнал гайд по тем же критериям сам. Найдено и исправлено:

1. **`git clone <адрес репозитория>`** — нетехнический читатель вставит плейсхолдер буквально и получит ошибку. Добавлено явное предупреждение + откуда взять токен бота (@BotFather, `/newbot`).

3. **Скрытое ограничение WSL** — даже с systemd бот стартует лишь после входа в Windows и открытия WSL. Названо прямо, чтобы не создавать ложного ожидания «служба сама поднимется».
4. **Добавлена проверка успеха** после запуска (`/ping` в Telegram) — раньше шаг 6 заканчивался ничем.
