# Ozon MCP — правила и устройство

Читать, когда меняешь или чинишь `ozon`-сервер, цены/регион Ozon, его таймеры или RAM-лимит. Переписано из AGENTS.md в V-48 (17.10.2026) без изменения смысла; адреса хостов намеренно не приведены (репозиторий публичный) — они вне git в `/home/kesha/projects/kesha-tg-bot/.orchestra/inventory.local.md`.

Кеша ищет товары, цены и отзывы Ozon через отдельный MCP-сервер `ozon` (6-й в `.mcp.json`). Внедрён в #7 (07.2026), доработки #9 и `ozon-fix` (`.orchestra/tasks/7/`, `9/`, `ozon-fix/`).

## Почему отдельный сервер на российском хосте
Антибот Ozon (Variti) жёстко блокирует IP прод-хоста во Франции (`fab_nmk` + «выключите VPN»). Российский IP проходит challenge `fab_chlg`, поэтому MCP крутится на российском сервере; прокси не нужен, сам сервер и есть RU-выход. Причина решения: измерено при #7, иначе Ozon недоступен.

```
Кеша (прод) → .mcp.json "ozon" = bare `ssh -T ozon@<ru-host>`
   → forced-command wrapper → node …/ozon-mcp-server/src/index.js (репа eduard256/ozon-mcp-server)
   → один долгоживущий headless Chromium проходит Variti, тянет composer-api JSON
```

## Тулы
`ozon_search` (sku, name, price, **ourPrice**, oldPrice, discount, rating, reviews, brand, url, image), `ozon_product_details` (карточка: цены, наличие, продавец, характеристики, описание, картинки), `ozon_product_reviews` (author, score, comment, pros, cons, date, hasPhotos).

## Правила и причины
- **`ourPrice` — оценка, не цена.** `ourPrice = round(cardPrice × 0.8949)` — цена «с Ozon-аккаунтом» без логина. Коэффициент подобран на 5 SKU (разброс ±0.1 %, #9, 07.2026; прежний 0.893 дал промах). `price` — публичная «с банками». Точная аккаунт-цена требует логина — не делаем; разница в том, что аноним видит не тот тариф `premiumSubscribe`. Не выдавать `ourPrice` за точную цену.
- **Регион = Красноярск, fail-closed.** Регион форсится куками из `krsk-state.json` (сняты один раз кликом по карте). `browser.js` грузит storageState по абсолютному пути и сверяет регион; не Красноярск → автозапуск `refresh-region.sh` (повторный захват, один ретрай) → если не помогло, тул возвращает `isError`, а не московские цены. Куки живут ~6 дней, а не 365 → превентивный `ozon-region-refresh.timer` раз в 5 дней. Ручное обновление: `node capture-region.mjs headless`. Причина fail-closed: московские цены для красноярского пользователя хуже отсутствия ответа.
- **RAM-защита прода.** На том же хосте живут другие сервисы (3 GB RAM). Пользователь `ozon` сидит в своём `user-<uid>.slice` с `MemoryMax=800M`, `MemorySwapMax=0` (systemd drop-in). Пик реального запроса ~306 MB. OOM бьёт только этот слайс (проверено kill-тестом #7), остальные сервисы живы. Браузер закрывается после 10 минут простоя.
- **Чистка зомби — только от root.** `kill-stale.sh` (root systemd timer, каждые 20 мин) убивает `index.js` ozon, чей родитель sshd не имеет ESTABLISHED-сокета (или PPID=1) и возраст > 2 ч. Критерий — состояние сокета, а не возраст: MCP-сессия долгоживущая. Запуск не от root недопустим: `ss` под пользователем `ozon` видит 0 процессов и убил бы живые сессии (пойман в тесте `ozon-fix`, 07.2026). Патчи: `.orchestra/tasks/ozon-fix/`.
- **Доступ.** Ключ прод-пользователя стоит в `authorized_keys` пользователя `ozon` с forced-command (`no-pty`, без shell). При EOF или обрыве SSH `index.js` сам закрывает Chromium (сирот нет).

## Известные ограничения
Нет истории цен; отзывы обрезаются (лимит 1–30); первый вызов ~13 с (антибот), дальше 0.3–1 с; данные берутся из внутреннего composer-api и могут смениться без предупреждения. Фильтры по бренду/типу достижимы (фасеты есть в raw JSON, #9), но не реализованы — см. TODO.md.
