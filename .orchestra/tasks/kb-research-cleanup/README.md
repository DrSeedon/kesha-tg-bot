# KB research cleanup

Дата: 2026-09-10. Ветка: `cleanup/research-kb`.

## Что проверено

Прочитаны общая политика knowledge Orchestra, две текущие темы KB и их исходные
доказательства: `.orchestra/kb/telegram-ingress.md` + `.orchestra/tasks/32/`,
`.orchestra/kb/context-compaction.md` + `.orchestra/tasks/34/`. Для ingress
подтверждено: в установленном aiogram 3.30.0 `Message.rich_message` проходит
в fallback при пустых `text`/`caption`, а JSON сериализация сохраняет распознанные
структурные и media-поля; неизвестные discriminator-значения падают до handler.
Для compaction подтверждено: same-batch admission остаётся доказанным только как
исследовательский контракт, а crash durability, точный Codex 95% и безопасный replay
провайдерского отказа остаются пробелами. План #34 не является результатом запуска.
